# Samriddhi Das — Portfolio

My personal portfolio website — a single-page site with a dark, code-inspired aesthetic.

🔗 **Live site:** https://samriddhi-2005.github.io

## About

This site showcases my background as a Computer Science undergraduate at KIIT University, my technical skills, work experience, and featured projects.

## Built With

- HTML5 & CSS3 (custom design system, no framework)
- Vanilla JavaScript (animated background, typewriter effect, scroll-reveal animations)
- [Sora](https://fonts.google.com/specimen/Sora) & [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) via Google Fonts

## Features

- Animated, mouse-reactive wireframe background (canvas-based)
- Typewriter-effect tagline in the hero section
- Scroll-triggered fade-in reveals
- Fully responsive layout (mobile, tablet, desktop)
- Direct links to GitHub repos for each featured project
- Accessible focus states and reduced-motion support

## Sections

- **About** — background, interests, and technical skill groups
- **Experience** — internship and work history
- **Projects** — featured projects with descriptions, tech stacks, and GitHub links
- **Contact** — email, GitHub, and LinkedIn
- **Education & Certificates** — academic background and certifications

## Run Locally

This is a static site — no build step required.

```bash
git clone https://github.com/Samriddhi-2005/Samriddhi-2005.github.io.git
cd Samriddhi-2005.github.io
```

Then open `index.html` in your browser.

## Deployment

Hosted via [GitHub Pages](https://pages.github.com/), served directly from the `main` branch.
